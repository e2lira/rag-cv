# Auditorías archivadas

Aquí se archiva el **Informe de Auditoría** de todo PR cuyo veredicto haya sido `FAIL`
(ADU-PROCESO §9), con el nombre `RFC-000N-pr<N>.md`.

No se archivan los `PASS`: viven como comentario del PR y no aportan nada al leerlos después.
Los `FAIL` sí, porque el patrón de lo que se rompe repetidamente es lo que debe acabar
modificando el RFC, el contrato de auditoría o la rúbrica transversal del Auditor.

Cada archivo conserva el informe tal cual lo emitió el Auditor, sin edición posterior.
